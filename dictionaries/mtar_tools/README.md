# Animation name dictionaries

From mctrollin's [Fox Engine MTAR Tools](https://github.com/mctrollin/fox_engine_mtar_tools_blender)
(GPL-3.0-or-later; commit `7fa90e5`), `dic/str32/` and `dic/path64/`.

* `skl_dictionary.txt`: skeleton bone names (`SKL_...`, `StrCode32`/`StrCode64`)
* `rig_dictionary.txt`: rig unit / animation track unit names (`RIG_...`)
* `param_dictionary.txt`, `events_dictionary.txt`: clip parameters and motion events
* `gani_dictionary.txt`, `shader_dictionary.txt`: old-format GANI node names
* `mtar_dictionary.txt`: `.gani` clip paths (without extension)
